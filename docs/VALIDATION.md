## 自动化测试覆盖

### 文献与访问控制

- 使用实际 PDF、SQLite、本地 Qdrant 与 API 接口验证文献处理；测试中的向量与重排模型使用模拟实现。
- 覆盖访问令牌校验、文献用户隔离、检索范围、引用编号检查与空证据行为。
- 验证 PDF 文件与原文来源数据的对应关系，不以自动化通过数量代替问答质量评价。

### 流式问答

- 检查输出预算、推理选项与流式参数的请求构造，以及两种 token 参数的互斥处理。
- 覆盖长度终止、上游连接中断、缺失结束标记、只有思考而无正文等异常状态。
- 验证不完整回答中的正文保留与引用校验，未知引用编号被拒绝。
- 覆盖 401、403、404、429、500 等上游错误，不向客户端返回平台密钥或模型内部思考正文。
- 前端测试覆盖中文 UTF-8 分片、末行无换行、流内错误、提前 EOF、空闲超时和断开连接。

### 图片任务

- 验证模型 ID、接口地址、认证头、单张 2K、关闭组图、Base64 返回及水印参数。
- 覆盖平台错误、超时、非法 Base64、缺失图片和返回外部 URL 等响应。
- 验证相同请求编号的任务复用、不同参数冲突、并发上限与不自动重试行为。
- 验证草稿、任务、详情与文件下载的用户隔离；使用测试数据库和文件系统检查保存及重新打开后的读取。
- 验证未配置图片模型时文献问答仍可工作，空检索结果不触发配图描述生成。

## 真实图片接口记录

单次测试配置为方舟 `/api/v3/images/generations` 接口与 `doubao-seedream-4-0-20260415`，请求生成白底蓝色圆形，返回记录摘要如下：

```text
MODEL: doubao-seedream-4-0-20260415
HTTP_STATUS: 200
RESULT: SUCCESS
```

该记录证明测试时该配置可以返回有效图片；测试直接调用模型平台，没有经过网页、项目任务队列和文件下载接口，因此不构成前后端完整生图流程的验收结果。

## 复现方法

项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-test.txt
.\.venv\Scripts\python.exe -m pytest -q
cd frontend
npm ci
npm test
npm run build
```

自动化测试不调用真实收费模型。`requirements-tested.txt` 是历史测试环境记录，不是完整依赖锁文件；运行环境安装入口为 `requirements.txt`。已记录的 Starlette/httpx 弃用警告不影响上述测试完成。

## 验证边界

- HTTP Mock 测试不能证明真实账号权限、平台额度、网络稳定性或模型输出质量。
- 文本请求预算的测试只验证字段构造，没有验证真实模型的最大上下文、最大输出或超长回答质量。
- 未完成真实浏览器端到端自动化测试；输入框恢复的历史检查来自代码审查及 TypeScript 构建。
- 尚无固定人工标注问答集的召回率、引用支持率或基线对照结果，也没有公网可用性与并发压力测试结果。
- 纯扫描 PDF、图像理解、完整多轮上下文与精确科学绘图不在当前功能验证范围内。

功能与协议说明见 [技术架构与实现](DEVELOPMENT.md) 和 [API 接口](API.md)。
